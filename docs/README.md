# Couchbase MCP Server — narrative docs

This is a story-style guide to the Couchbase MCP Server: what MCP is, why
this server exists, how it works internally, and how to run and operate it.
It's meant to be read start to back, building from basics to advanced.

For precise, up-to-date reference (env vars, CLI flags, tool tables), see
the [README](../README.md) and [DOCKER.md](../DOCKER.md) at the repo root
instead — this series is a companion to those, not a replacement.

See [CLAUDE.md](./CLAUDE.md) for the full planned chapter outline and the
process for contributing the next chapter.
